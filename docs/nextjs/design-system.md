# Design system

The UI of a Next.js app comes from `@argos-identity/argos-design-system`.

- Before you write or change UI, read the package's `DESIGN.md` and, under its `docs/design/`, the contract of each component that you use, and follow them. Read the copy installed in the app's `node_modules/@argos-identity/argos-design-system/`, because the rules change with the version, and a copy from another version or from the package's repository can be wrong for the app.
